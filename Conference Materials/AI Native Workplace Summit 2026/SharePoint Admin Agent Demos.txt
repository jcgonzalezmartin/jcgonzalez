#Demo #2: SharePoint Admin Agent prerequisites & Access options
################################################################################################
-> Prerequisites: 
	-> Licensing
	-> Roles that can use the SharePoint Admin Agent:
		-> SharePoint Advanced Management Role - Access to all SAM features
		-> SharePoint Online Admin - Access to SPO Admin features + almost all SAM features
		-> Global Admin - Remember to follow the principle of least privilege
	-> The other surface options -> Accessing the SharePoint Admin Agent in Teams

#Demo #4: Multi-variable site search + Storage skills
################################################################################################

-> Multi-variable site search:
	-> Find inactive sites larger than 100 GB with external sharing enabled

	-> Show me storage information. Include my storage quota, storage used, and site counts

		-> Break this down by file types (videos vs documents vs backups)
	-> Which sites grew fastest in the last 90 days?

################################################################################################
#Demo #5: Lifecycle + Permissions skills
################################################################################################

-> Lifecycle skill:
	-> Show sites without an owner 
	-> Identify sites with low activity by department
	-> Which sites are candidates for archive this quarter?
	-> Identify sites that have not been accessed in the last 18 months
	-> How much storage and governance overhead could be reduced by archiving inactive sites?
	-> Create a site lifecycle management policy to manage inactive sites -> The agent provide guidance about Site lifecycle management policies, but it cannot create them

-> Permissions skill:
	-> Which sites are overshared and what are the risk levels for these sites?
	-> Give me details about Teams-connected sites that are overshared
	-> Show me the most overshared sites in my tenant ranked by business risk -> Not supported yet
	-> Identify content that is accessible by Everyone Except External Users and explain the associated risks -> Not supported yet

-> Microsoft 365 Copilot Readiness:
	-> What are the top 20 sites that should be remediated before expanding Copilot deployment?
	-> Show me the departments/sites with the highest risk of oversharing affecting Copilot responses
	-> Estimate how much content in my tenant could be unintentionally surfaced through Copilot because of excessive permissions
